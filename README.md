# homeroot-pub

Generic firmware packages for HomeRoot devices. Each directory under `firmware/` is one package. Copy a package, fill in `secrets.yaml`, and set the lamp file for your fixture.

Secrets stay out of git. `secrets.yaml` is gitignored.

| Package | Hardware |
| --- | --- |
| [MJXDD01SYL](firmware/MJXDD01SYL/) | Yeelight Mi Smart LED Ceiling Light 450 (`yeelink.light.ceiling22`) |
